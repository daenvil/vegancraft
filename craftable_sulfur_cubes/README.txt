# Craftable Sulfur Cubes (v1.0.1, for Minecraft 26.3+)

This datapack adds inanimate sulfur cubes that can be crafted.

- This datapack was made by Daenvil, its official pages are:

  - On my website: https://daenvil.github.io/MCDatapacks/craftable_sulfur_cubes.html

- This version was published on the 7th of October 2026. Check the webpages above for possible updates.

## Installation

- Drop the datapack zip file inside the "datapacks" folder of your world folder (<your minecraft folder>/saves/<your world>/datapacks/).

## Features

Craft a sulfur cube with leather and sulfur. Right click with the sulfur cube on the ground to spawn it. You can use the sulfur cube as you would a regular one, but this one will always be inanimate.
